# Telegram-бот-визитка с записью

Демонстрационный бот для малого бизнеса: барбершопы, кофейни, автосервисы. Показывает услуги и цены, записывает на выбранное время и передаёт вопросы администратору.

Всё содержимое — тексты, услуги, цены, слоты времени, адрес — лежит в одном файле `config/scenario.json`. Чтобы адаптировать бота под другого клиента, код менять не нужно.

## Что умеет

- `/start` — приветствие и кнопки услуг;
- выбор услуги — цена, длительность и варианты времени кнопками;
- подтверждение записи с адресом, часами работы и телефоном;
- кнопка «Задать свой вопрос» — вопрос уходит администратору в отдельный чат;
- кнопка возврата к списку услуг, защита от неизвестных кнопок и пустых сообщений.

## Структура

```
config/scenario.json   тексты, услуги, цены, слоты, реквизиты
src/scenario.py        сценарий: чистая логика, без Telegram
src/telegram.py        клиент Bot API на стандартной библиотеке
src/bot.py             запуск бота (long polling)
src/console_demo.py    прогон сценария в консоли
tests/test_scenario.py тесты сценария
```

## Запуск

1. Скопируйте `.env.example` в `.env` и вставьте токен от `@BotFather`:

```
BOT_TOKEN=123456:AA...
```

2. Запустите бота:

```
py -3 src/bot.py
```

Зависимостей нет: только стандартная библиотека Python 3.11+.

## Проверка без Telegram

```
py -3 -m unittest discover -s tests -t .
py -3 src/console_demo.py
```

`console_demo.py` проигрывает сценарий в терминале: видно тексты, кнопки и что уходит администратору. Скриншоты этого прогона идут в материалы кворка.

## Как менять тексты

Правится только `config/scenario.json`:

- `business` — название, адрес, часы работы, телефон, `admin_chat_id` для вопросов;
- `texts` — все сообщения бота с подстановками `{name}`, `{price}`, `{slot}`, `{address}`;
- `services` — список услуг: `id`, `title`, `price`, `duration`, `slots`.

Новая услуга — ещё один объект в `services`, кнопка появится сама.

## Что дальше
